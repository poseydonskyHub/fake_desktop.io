# Fake Windows Desktop — prank page

Светло-фиолетовый рабочий стол с закреплёнными приложениями, одним подозрительным файлом, синим экраном и розовым поздравлением с ASCII-портретом.

## Запуск
Открой `index.html` в браузере.

## GitHub Pages
1. Создай публичный репозиторий.
2. Загрузи `index.html` в корень репозитория.
3. Открой **Settings → Pages**.
4. Выбери **Deploy from a branch**, ветку `main`, папку `/(root)`, нажми **Save**.
5. Сайт появится по адресу `https://USERNAME.github.io/REPOSITORY/`.

## Взаимодействие
- Двойной клик по `НЕ_СМОТРИ_СЮДА.exe` запускает анимацию.
- После синего экрана появляется розовое поздравление с летающими сердечками.
- Кнопка «На весь экран» включает fullscreen после клика.

Это безопасная визуальная шутка: страница не блокирует устройство, не меняет файлы и не вызывает настоящий сбой Windows.
